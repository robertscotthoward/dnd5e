## Ability Scores

Every character has six ability scores, each with a modifier = (score − 10) / 2 (rounded down).

- **Strength** — Melee attacks, Athletics checks, carrying capacity
- **Dexterity** — Ranged attacks, AC (light armor), Stealth, Initiative
- **Constitution** — HP maximum, concentration saves
- **Intelligence** — Arcane spellcasting, Investigation, History
- **Wisdom** — Divine spellcasting, Perception, Insight, Survival
- **Charisma** — Social skills, some bard/paladin/sorcerer/warlock spells

## Character Sheet

Open the character sheet with the **Sheet** button in the game header bar. It shows:

- Ability scores and modifiers
- Class features and proficiencies
- Equipped items
- Spell slots (casters only)
- HP, AC, speed

## Leveling Up

When you earn enough XP the DM triggers a level-up dialog. Choose:

- Roll or take average for your new hit die
- Ability Score Improvement (ASI) at levels 4, 8, 12, 16, 19
- Class-specific features

## Rests

- **Short Rest** (1 hour) — Spend hit dice to recover HP; some class features recharge
- **Long Rest** (8 hours) — Restore all HP, all spell slots, most class features

Use the **Short Rest** and **Long Rest** buttons in the action bar during Exploration mode.

## Conditions Reference

| Condition | Effect |
|-----------|--------|
| Blinded | Auto-fail sight; attacks against you have advantage; your attacks have disadvantage |
| Charmed | Cannot attack charmer; charmer has advantage on social checks against you |
| Deafened | Auto-fail hearing; not affected by verbal components |
| Frightened | Disadvantage on checks/attacks while source is in sight; cannot move closer |
| Grappled | Speed 0 |
| Incapacitated | No actions or reactions |
| Invisible | Attacks against you have disadvantage; your attacks have advantage |
| Paralyzed | Incapacitated; auto-fail Str/Dex saves; attacks within 5 ft. crit |
| Petrified | Incapacitated; resistant to all damage; auto-fail Str/Dex saves |
| Poisoned | Disadvantage on attack rolls and ability checks |
| Prone | Disadvantage on attacks; melee attacks against you have advantage |
| Restrained | Speed 0; disadvantage on attacks; attacks against you have advantage |
| Stunned | Incapacitated; auto-fail Str/Dex saves; attacks against you have advantage |
| Unconscious | Incapacitated; prone; auto-fail Str/Dex saves; attacks within 5 ft. crit |
