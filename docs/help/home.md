## Getting Started

Press **F1** from anywhere in the app to open this help overlay. Press **Escape** to close.

The chat window is your primary interface with the Dungeon Master. Type actions or questions and the DM responds in real time.

## Quick Reference

- **F1** — Open/close help
- **Escape** — Close help overlay
- **F4** — Toggle world map
