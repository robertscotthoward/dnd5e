# Controls

[← Home](home.md)

## Keyboard Shortcuts

- **F1** — Open/close help overlay
- **F4** — Toggle world map
- **Escape** — Close any open overlay

## Chat Input

Type your action or question in the chat box and press **Enter** to submit. The DM processes your message and responds.

During combat, only the active player's messages are processed. Other players see a "waiting for X" notice.

## Action Bar

The action bar at the bottom of the chat panel shows context-sensitive buttons based on the current game mode:

- **Exploration** — Move, Search, Rest
- **Combat** — Attack, Cast Spell, Dash, Disengage, Dodge, Help
- **Social** — Talk, Persuade, Intimidate, Deceive
- **Travel** — no actions; travel resolves automatically

Buttons are disabled (with tooltips explaining why) when your character cannot use them — for example, a silenced character cannot cast verbal spells.

## Sidebar Panels

- **The Party** — Party members with HP bars and condition badges
- **Location** — Current area name and description
- **Initiative** — Turn order during combat
- **Quests** — Active quests and milestones
- **NPCs** — Known NPCs and their disposition toward the party
